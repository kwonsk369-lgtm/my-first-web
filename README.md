# 배전공사 단가 · 사토장 · 학습 대시보드 (Google Apps Script 웹앱)

배전공사 노임단가, 엔지니어링 임금(전기), 순환골재 단가, 대구·경북 사토장(도로거리), 간접공사비(제비율) 적용기준, 업무기준 퀴즈를 한 화면에서 보는 Apps Script 웹앱입니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `Code.gs` | 웹앱 진입점, 단가 불러오기, 사토장(공공데이터 API), 네이버 주소·도로거리 |
| `Index.html` | 화면(대시보드·퀴즈) |
| `RateTable.gs` | 제비율 엑셀 자동 확인·변환 |
| `RateData.gs` | 제비율 기본 표(2026.04.13 기준) |

## 설치
1. script.google.com → 새 프로젝트 → 위 4개 파일을 같은 이름으로 만들고 붙여넣기
2. 프로젝트 설정 → **스크립트 속성**에 아래 키를 직접 등록 (코드에는 키가 없습니다)
3. 편집기에서 `setup` 실행 → 권한 승인, 이어서 `installTriggers` 1회 실행
4. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)

## 스크립트 속성 (값은 각자 발급 — 절대 코드·저장소에 넣지 마세요)
| 이름 | 필수 | 설명 |
|---|---|---|
| `NAVER_CLIENT_ID` | ✔ | 네이버 클라우드 Maps Client ID (Geocoding, Directions 5 체크) |
| `NAVER_CLIENT_SECRET` | ✔ | 네이버 클라우드 Maps Client Secret |
| `DATA_GO_KR_KEY` | ✔ | 공공데이터포털 일반 인증키 (토석정보공유서비스 /SoilComList) |
| `UPLOAD_PIN` | 선택 | 제비율 엑셀 직접 올리기 비밀번호 |
| `DEFAULT_RADIUS_KM`, `APP_TITLE` | 선택 | 화면 기본값 |
