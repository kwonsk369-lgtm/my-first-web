# 배전공사 단가 대시보드

배전공사 노임단가 · 순환골재 단가 · 근처 사토장 · 엔지니어링 노임단가를 한 화면에서 보는 웹페이지입니다.

- 화면: GitHub Pages (`index.html`)
- 데이터: Google Apps Script 웹앱 (`Code.gs`) — 사이트 수집, 날짜 저장, 거리 계산 담당

## 연결 방법
`index.html` 안의 `var API_URL = '';` 따옴표 안에 Apps Script 웹앱 주소(`https://script.google.com/macros/s/…/exec`)를 넣으세요.

## 자료 출처
- 대한건설협회 건설업 임금실태조사
- 한국건설자원협회 순환골재 판매현황
- 토석정보공유시스템 (사토장 목록은 구글 시트에 붙여넣어 사용)
- 한국엔지니어링협회 엔지니어링업체 임금실태조사
